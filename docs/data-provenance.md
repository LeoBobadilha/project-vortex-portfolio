# Public data provenance

Three approved aggregate CSV files are distributed in `public/data/`. The current browser code fetches `monthly_portfolio_results.csv` and `benchmark_summary.csv`; `annual_portfolio_results.csv` is the third distributed CSV and is not requested by current JavaScript. The files support historical portfolio views for P6+SIZE+CE and the separate P6 baseline. PSC reconciles to 324 records and 526 contract units: R$23,551 gross, R$3,156 C30 costs applied once and R$20,395 net. No row-level trade ledger is embedded.

The charts are selected examples, not a distribution sample. Public versions mask exact time and price scales, family identifiers and individual results.
