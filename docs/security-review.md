# Public Security Review

Review date: 2026-11-05. This review covers website source, generated `dist/`, public aggregate data, images, documentation and repository history.

The site is a static HTML, CSS and browser-native JavaScript application. It has no backend, trading endpoint, broker connection, account data, or authentication. The chart engine is bundled locally under the Apache 2.0 license; no third-party runtime CDN is used. Three approved aggregate CSVs are distributed; portfolio JavaScript fetches the monthly portfolio and benchmark summary files. The replay loads translated, session-relative full-session OHLC data and requests the completed position summary only after reaching the modeled exit. The website build reproduces `dist/` from `src/` and approved public assets.

The release candidate displays six inspected clean Power BI Desktop captures (pages 01-03 and 12-14) in an accessible gallery. Eight screenshots for PBIP pages 04-11 remain withheld because the former captures contained Zoom or desktop overlays; no replacements have been fabricated or recaptured. The companion public PBIP retains all 14 pages.

The published base for this release candidate is the screenshot-withdrawal update on website `main`; the GitHub Pages deployment history is available from the [repository workflow](https://github.com/LeoBobadilha/project-vortex-portfolio/actions/workflows/deploy-pages.yml). The initial `v1.0.0` tag remains unchanged. This review is a source and asset audit, not a claim of an external secret-scanner result.

The current published trees withhold the affected images, but prior public commits and the original release tag still contain historical image blobs. This release did not rewrite history. A history rewrite, if approved, requires a separate privacy-remediation decision.

This release candidate replaces the previous fixed two-contract replay with a separately modeled one-plus-one research case. Its two simulated fills map to distinct rows in a private frozen ledger; the raw ledger, unshifted series, exact date and clock, private event ID, and broader market archive remain excluded. The public candle geometry is preserved after a constant translation and elapsed-time transformation, so correlation with external market data remains possible. The result is not part of the PSC benchmark, Paper Live, or live-account performance. Re-run `scripts/audit_public_site.py` against the generated tree before release. Historical repository commits and the original `v1.0.0` tag still retain previously published screenshot blobs; no history rewrite was performed or authorized by this change.
