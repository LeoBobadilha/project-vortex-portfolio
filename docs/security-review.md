# Public Security Review

Review date: 2026-11-06. Scope: website source, generated `dist/`, public aggregate data, replay assets, screenshots, documentation and repository history.

The site is static HTML, CSS and browser-native JavaScript. It has no backend, broker/account connection, trading endpoint, authentication or live market feed. Lightweight Charts is bundled locally. Three portfolio aggregate CSVs are distributed; browser code fetches the monthly results and benchmark summary. The replay loads 107 translated, session-relative M5 candles and requests its completed-position outcome only after playback reaches the modeled exit.

The replay displays the source market session date, 30 September 2022. This date is represented by source epoch records; the source clock timezone is unauthenticated, so it is not a certified B3 local timestamp. Exact source timestamps, private event identifiers, unshifted prices and the wider archive remain excluded. Publishing the date with recognizable OHLC geometry materially increases external market-correlation risk. Entry 2 and the modeled exit are off WIN's five-point tick grid; BRL values are adjusted-price model arithmetic under the separate S2 research assumption, not exchange-executable performance, PSC results, Paper Live or live-account P&L.

The public PBIP contains 14 pages, and the website displays one genuine Power BI Desktop capture of each. All 14 were taken in one refreshed session on 2026-11-06 using a window-only capture, so other windows and notifications cannot appear in them, and each was pixel-reviewed. They replace all earlier images; none is fabricated or edited. The original v1.0.0 history still contains the earlier contaminated screenshot blobs, which show meeting UI, including participant names, and unrelated shared-screen market windows. Anyone with the repository can still retrieve them. Removing them from current trees did not erase those objects, and no history rewrite was performed. That requires separate approval.

Local checks are available in `scripts/audit_public_site.py`, `scripts/test_static_site.py` and `npm run test:replay`. `docs/public-file-manifest.json` records canonical LF hashes for text and exact-byte hashes for binaries, and the Pages workflow fails if it does not reproduce on Linux. This review does not claim an external secret-scanner result.
