# Technical stack

The portfolio is a static application built with semantic HTML, custom CSS and browser-native JavaScript. The aggregate portfolio views consume three approved CSV files; current browser code fetches the monthly results and benchmark summary. The interactive replay uses a locally bundled TradingView Lightweight Charts engine with a small native-JavaScript position-state model and two sanitized JSON resources: translated, session-relative M5 candles and a completed-position outcome loaded only after the modeled exit. SVG renders the portfolio charts. Node.js builds `dist/` for GitHub Pages. There is no server runtime, authentication layer, broker connection, trading API or live market feed. The companion report uses Power BI, Power Query M and DAX.
